# Okyema Command Frame brand assets

This is the production asset pack for the approved **Okyema Command Frame** identity.

## Story

- Three cyan-to-blue input routes represent conversations, calendar and documents.
- The blue centre is Okyema's executive context and decision core.
- Two blue-to-violet output routes represent decisions and delegated actions.
- The surrounding frame represents governance, confidentiality and control.

## Theme use

- `okyema-mark-light.svg` is the primary mark for light surfaces.
- `okyema-mark-dark.svg` is the reversed mark for dark surfaces.
- Never recolour, rotate, stretch, separate or reorder the routes.

## Core colours

- Obsidian `#0B1020`
- Executive blue `#2956B8`
- Electric blue `#347DF2`
- Luminous cyan `#36D7EB`
- Intelligence violet `#7457FF`
- Cloud `#F5F7FB`
